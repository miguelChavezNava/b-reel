# B-Reel Mobile App

This project is a mobile app created to allow users to rank 10 movies through simple side-by-side comparisons, letting lists to be quickly made and shared easily with others.

The movie data was gathered from the <a href="https://www.omdbapi.com/">Open Movie Database<a> and then presented on a list with separate elements, showing the director, release year, and rating. Posters were curated and added onto the project through simple downloads, being loaded for each movie by their name. The ranking algorithm was made through implementing merge sort with these side-by-side comparisons creating and deleting branches, ranking the movies as the tree grows and shrinks until an order is determined.

This app was made with React for the user interface and coded with TypeScript, being publicly hosted through Expo Go.
